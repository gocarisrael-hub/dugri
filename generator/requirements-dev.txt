# Python packages needed to RUN THE GENERATOR'S TESTS (`npm run test:py`).
#
# This is not the runtime contract. The production image installs what the
# generator itself needs through apk (see Dockerfile: python3 + py3-pillow +
# py3-pikepdf + ghostscript + chromium); it deliberately carries no pip layer.
# Keep the two in step:
#
#   pillow  — used by the generator at runtime AND by the tests
#   pikepdf — used by press.py at runtime (writing TrimBox/BleedBox and the
#             OutputIntent) AND by its tests; the image gets it from apk as
#             py3-pikepdf
#   numpy   — TEST-ONLY (test_render_page's glyph-shape comparison); no module
#             under generator/ imports it outside tests, which is why the image
#             ships without it
#   pytest  — the runner
#   fonttools — TEST-ONLY and TOOL-ONLY. scripts/set_photo_card_copy.py sets the
#             pawn card's static copy into outlines from the words written in
#             the artwork; the test only re-runs it in --check mode to prove the
#             outlines still say what the SVG says they say. The production image
#             never runs it — it only prints the paths it left behind. The [woff]
#             extra pulls brotli, without which the self-hosted Heebo .woff2 the
#             generic card is set in cannot be opened at all.
#
# Ghostscript is a BINARY, not a pip package: press.py shells out to it, and the
# tests that need it skip when it is absent rather than fail.
#
# Pinned loosely: these are stable, widely-packaged libraries and the tests do
# not depend on version-specific behaviour.
pytest>=8
pillow>=10
numpy>=1.26
pikepdf>=8
fonttools[woff]>=4.50
